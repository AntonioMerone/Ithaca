# Privacy

Ithaca e una PWA locale: non richiede account, login, backend o server applicativo.

I dati dei viaggi, budget, timeline, checklist, note e backup importati restano nel browser del dispositivo tramite localStorage. L'app non invia automaticamente dati a servizi esterni e non sincronizza informazioni tra dispositivi.

Se cancelli i dati del sito dal browser, svuoti la cache in modo completo o usi funzioni di pulizia del dispositivo, i dati locali di Ithaca possono essere eliminati.

Prima di cambiare dispositivo, cancellare dati o fare test distruttivi, usa la funzione Esporta backup JSON dalla Home. Per trasferire i dati su un altro dispositivo, esporta il file JSON dal primo browser e importalo nel secondo.

Ithaca non include analytics, account utente, cloud sync, AI, documenti caricati su server o condivisione automatica.
